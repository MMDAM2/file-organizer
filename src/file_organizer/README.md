# Source Files

## File structure

```none
-> __init__.py
-> main.py
-> organizer.py
-> categories.py
```

## PR Requirements

> [!NOTE]
> Not all of the requirements below are necessary if app's main behavior still works

- Do not remove the shebang line in `main.py`
- Do not change the imports unless needed
- You can and have the power to change the extension list in `categories.py`
- Do not change the `organizer.py` behavior
- Any changes should be outside of app's logic
